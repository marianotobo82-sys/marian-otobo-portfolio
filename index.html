Here's a simple step-by-step guide to publishing the portfolio on GitHub Pages:

Step 1 — Create a GitHub account Go to github.com and sign up for a free account if you don't have one.

Step 2 — Create a new repository

  • Click the "+" icon at the top right and select "New repository"
  • Name it exactly: marian-otobo-portfolio (or any name you like)
  • Set it to Public
  • Tick "Add a README file"
  • Click "Create repository"

Step 3 — Upload the HTML file

  • Inside your new repository, click "Add file" → "Upload files"
  • Drag and drop the marian_otobo_va_portfolio.html file
  • Important: Rename it to exactly index.html before uploading (just rename it on your computer first)
  • Scroll down and click "Commit changes"

Step 4 — Enable GitHub Pages

  • Click "Settings" (tab at the top of the repository)
  • Scroll down the left sidebar and click "Pages"
  • Under "Branch", select "main" from the dropdown, leave the folder as "/ (root)"
  • Click "Save"

Step 5 — Get your live link

  • Wait about 1–2 minutes, then refresh the Pages settings
  • GitHub will show you a green banner with your live URL, which will look like: https://yourusername.github.io/marian-otobo-portfolio

That's it — the portfolio is live and shareable! You can paste that link on your LinkedIn profile, in job applications, or anywhere you like. Whenever you want to update the portfolio, just re-upload a new index.html to the same repository and the live site updates automatically.
